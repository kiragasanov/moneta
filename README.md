# Монета

Клиентское веб-приложение для учета и анализа личных финансов. Курсовая работа, КИКТ ВВГУ, 2026.

Приложение позволяет вести учет доходов и расходов по счетам и категориям, задавать месячные бюджеты и анализировать финансы с помощью графиков: динамика по месяцам, структура расходов, накопления нарастающим итогом.

## Стек

| Часть         | Технологии                                                |
| ------------- | --------------------------------------------------------- |
| Клиент        | HTML5, CSS3, JavaScript (ES-модули), Chart.js             |
| Сервер        | Node.js, Express                                          |
| База данных   | SQLite (встроенный модуль `node:sqlite`), SQL-миграции    |
| Качество кода | ESLint, Prettier, тесты на `node:test`, коллекция Postman |

## Архитектура

```
client/            клиентская часть (SPA)
  index.html
  css/style.css
  js/
    api.js         обращения к REST API
    router.js      маршрутизация по hash
    components/    модальные окна, графики, списки
    views/         страницы приложения
server/            серверная часть
  index.js         запуск сервера
  app.js           настройка Express и маршрутов
  routes/          REST API (контроллеры)
  repositories/    SQL-запросы к базе данных
  db/              подключение, миграции, демо-данные
  middleware/      обработка ошибок
  utils/           валидация, работа с деньгами и датами
tests/             автоматические тесты API
docs/              коллекция запросов Postman
```

## Запуск

Требуется **Node.js 22.13** или новее.

```bash
# 1. Установить зависимости
npm install

# 2. (необязательно) создать файл настроек
cp .env.example .env

# 3. (необязательно) заполнить базу демонстрационными данными за полгода
npm run seed

# 4. Запустить сервер
npm start
```

После запуска приложение доступно по адресу http://localhost:3000. База данных создается автоматически в папке `data/`, миграции применяются при старте сервера.

## REST API

Все ответы в формате JSON. Суммы передаются в рублях, в базе хранятся в копейках.

| Метод             | Адрес                                                                     | Назначение                              |
| ----------------- | ------------------------------------------------------------------------- | --------------------------------------- |
| GET               | `/api/accounts`                                                           | список счетов с балансом                |
| POST, PUT, DELETE | `/api/accounts/:id`                                                       | создание, изменение, удаление счета     |
| GET               | `/api/categories?type=`                                                   | список категорий                        |
| POST, PUT, DELETE | `/api/categories/:id`                                                     | управление категориями                  |
| GET               | `/api/transactions?from&to&type&categoryId&accountId&search&limit&offset` | операции с фильтрами                    |
| POST, PUT, DELETE | `/api/transactions/:id`                                                   | управление операциями                   |
| GET               | `/api/budgets?month=`                                                     | бюджеты месяца с фактическими расходами |
| POST, PUT, DELETE | `/api/budgets/:id`                                                        | управление бюджетами                    |
| GET               | `/api/stats/summary?from&to`                                              | доходы, расходы, баланс за период       |
| GET               | `/api/stats/by-category?from&to&type`                                     | распределение по категориям             |
| GET               | `/api/stats/by-month?months&until`                                        | динамика по месяцам                     |
| GET               | `/api/stats/insights?from&to`                                             | средний расход в день, крупнейшая трата |

Коды ответов: `200` успех, `201` создано, `204` удалено, `400` ошибка в данных, `404` не найдено, `409` конфликт, `500` ошибка сервера.

Коллекция для Postman: `docs/moneta.postman_collection.json`.
